# Solventa Android — Proyecto Final II

Android application repository for Solventa, developed by Grupo 2 for MISW4501 at Universidad de los Andes.

## Current status

This repository contains the initial collaboration setup. The Android project and its build configuration have not been added yet.

The case statement and the current course rubric define the requirements. Jira defines the approved work and acceptance criteria. The current Figma file defines the design system and screen designs. The [previous Android repository](https://github.com/JUANES545/solventa-app) is a reference, not the current specification.
